# The Future of NLG in the Age of LLMs

This is the code accompanying the paper "The Future of NLG in the Age of LLMs". In this paper, we perform a literature research to study the changing trends in the field of Natural Language Generation (NLG) and discuss the implications deriving from this. The code is released mainly for reproducibility purposes.

## Setup

Install [pandas](https://pandas.pydata.org/), [pybtex](https://pybtex.org/), and [plotly](https://plotly.com/python/).

Download the ACL Anthology [bibliography file](https://aclanthology.org/anthology.bib). We downloaded it on December 10, 2025.

Download [this file](https://huggingface.co/datasets/WINGNUS/ACL-OCL/blob/main/acl-publication-info.74k.v2.parquet). We used it to supplement missing abstracts prior to 2020 in the original ACL Anthology file.

Run the program with ```python bibscraper.py```.
